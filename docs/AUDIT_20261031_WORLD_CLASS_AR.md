## 4) القسم بقسم

> كل قسم: الدرجة · المقارنة · اللي اتجرّب · بيعمله زي أو أحسن من المرجع · أكبر فجوة · أهم 3 تغييرات. الأولوية: **P0** يكسر فلوس/بيانات/أمان، **P1** وجع يومي، **P2** تلميع.

### 4-1) الموقع العام والـSEO والدفع — 6.5
**المرجع:** Shopify Checkout (للدفع) + صفحات Coursera التسويقية (للـSEO).
**اتجرّب:** الموقع الحي (قراءة)، كود الحجز العام `orders/reserve`، ملفات nginx.
**بيساوي/أحسن:** السرعة (0.8 ث تحميل كامل، تتبع Google/Meta بيتحمّل بعد الخمول)، 51 رابط في الـsitemap، صفحات الكورسات متجهّزة (canonical + عنوان + JSON-LD خاص)، السعر مش بيتاخد من المتصفح أبداً (`public-orders.js:231`)، حماية rate-limit على 89 route عام.
**الفجوات:**
- **P1** الدفع بالكارت مش شغّال: تعليق الكود نفسه بيقول «Unused on production: no order has ever come through this route». يعني كل الإيراد تحويلات يدوية؛ Shopify/Stripe بتوصّل لأعلى تحويل بالدفع في نفس الصفحة.
- **P2** أي رابط غلط بيرجّع **200** بدل 404 (`deploy/nginx/mahad-web.conf.example:102-103`) — Google بيعتبرها soft-404.
- **P2** صفحات غير الكورسات (`/courses`, `/about`, `/contact`) HTML الخام بتاعها واحد وcanonical بتاعها `/` (`client/index.html:88`) لحد ما الـJS يشتغل؛ واتساب وفيسبوك وبينج مابيشغّلوش JS فمعاينة الرابط = الصفحة الرئيسية.
- **P2** روابط الـsitemap للكورسات من غير `/` في الآخر وnginx بيحوّلها 301.
**أهم 3 تغييرات:** (1) تفعيل Paymob على staging ثم الإنتاج بلينك دفع داخل الواتساب، (2) 404 حقيقي + canonical خاص لكل route، (3) sitemap بالـslash.

### 4-2) منطقة الطالب — 7.0
**المرجع:** Teachable/Coursera للتجربة، Moodle للعمق.
**اتجرّب:** 16 endpoint للطالب (كلها 200، أبطأها 249 مللي)، حماية الجلسة الواحدة/مشاركة الحساب (كود)، الصفحة `UserDashboard.tsx` (1,247 سطر).
**بيساوي:** مسارات وباقات، اختبارات بتقييم تلقائي، متطلبات سابقة، دفعات (cohorts)، إعادة دراسة، انتظار، تقدّم، شهادة بتحقق عام، منع مشاركة الحساب، تحدّث مع مساعد ذكي بيسلّم مبيعات/دعم.
**الفجوات:** PWA موجود (manifest + service worker) لكن مفيش تطبيق نيتف ولا محاضرات offline؛ مفيش اختبارات واجهة خالص (الـ admin والـ client = 0 ملف اختبار)؛ حماية الفيديو معتمدة على إعداد nginx (مشكلة «أول فيديو بس» اتكررت قبل كده)؛ صفحة واحدة ضخمة بتجمع كل حاجة.
**أهم 3:** تقوية الـPWA (إشعارات ومحاضرات محمّلة)، اختبارات واجهة لمسار «أدخل ← أشوف المحاضرة ← الاختبار ← الشهادة»، فحص صحة حماية الفيديو في كل نشر.
